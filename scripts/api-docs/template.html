Harmoni API

How an app signs in to a Harmoni server, and everything it can do once it has: search, play, likes, playlists, Spices, history and Harmoni Link. Every Harmoni server answers the same API at its own address.

  • OAuth 2.0 with PKCE
  • JSON over HTTPS
  • Bearer tokens, 1 hour
  • Server-Sent Events for Link
